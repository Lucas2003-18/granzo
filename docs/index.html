Instalação

Como instalar
o Granzo

O Granzo é distribuído como APK — o arquivo de instalação do Android. Siga os passos abaixo pela primeira vez; depois as atualizações são iguais.

1
Baixe o APK
Acesse github.com/Lucas2003-18/granzo/releases/latest e toque em granzo.apk para baixar. O arquivo vai para a pasta Downloads do seu celular.
2
Permita fontes externas
O Android vai perguntar se você quer instalar apps de fontes desconhecidas. Toque em Configurações e ative a permissão para o navegador ou gerenciador de arquivos.
3
Instale o APK
Abra a pasta Downloads, toque no arquivo granzo.apk e confirme a instalação. O ícone do Granzo vai aparecer na sua tela inicial.
4
Atualizações
Quando sair uma versão nova, repita os passos 1 e 3 — o Android instala por cima sem apagar seus dados.
⚠️ Aviso do Android
O Android exibe um aviso de "app de fonte desconhecida" porque o Granzo não está na Play Store. Isso é normal para APKs distribuídos diretamente. O código-fonte é público no GitHub — você pode inspecionar o que está instalando.
💡 Requisitos
Android 8.0 ou superior (API 26+). Funciona em qualquer fabricante: Samsung, Motorola, Xiaomi, etc. Não disponível para iPhone.
📦 Versão atual
A versão mais recente está sempre em releases/latest. O changelog de cada versão fica na própria página da release.
IA Financeira

Ativando o
assistente Gemini

O chat de IA usa o Gemini do Google. A chave é gratuita e fica salva só no seu celular — nenhum dado passa por servidor nosso.

01
Acesse o Google AI Studio
Entre em aistudio.google.com com sua conta Google. É gratuito, sem precisar de cartão de crédito.
02
Crie uma chave de API
No menu lateral, clique em Get API key → Create API key. Copie a chave gerada — ela começa com AIza.
03
Cole no Granzo
No app, acesse ⚙️ Config → Chave IA. Cole a chave no campo indicado e toque em Salvar chave.
04
Pronto — abra a aba IA
A aba 🤖 IA no menu inferior vai gerar um diagnóstico automático do mês assim que você abrir.
🔒 Como seu dado é usado
Ao usar o chat de IA, um resumo dos totais por categoria (ex: "Alimentação: R$ 800, Transporte: R$ 300") é enviado ao Gemini para gerar a análise. Descrições individuais de lançamentos não são enviadas. A chave fica só no seu celular.
Backup

Proteja seus
dados financeiros

O Granzo salva tudo localmente no seu celular. Se você trocar de aparelho ou limpar o app, os dados somem — por isso o backup manual é essencial.

✓ Recomendado
Exportar arquivo JSON
O método mais confiável. Gera um arquivo com todos os seus dados que você pode guardar onde quiser: WhatsApp, Google Drive, e-mail, pendrive.
⚙️ Config → Dados → Exportar backup JSON
📋 Como restaurar
Importar de volta
Se precisar restaurar — em um celular novo ou após reinstalar — basta importar o arquivo salvo. Todos os lançamentos, categorias e configurações voltam.
⚙️ Config → Dados → Importar backup JSON
⚠️ Lembrete importante
Faça backup pelo menos uma vez por mês. O Granzo avisa no Dashboard quando passou mais de 7 dias do último backup. Não ignore o aviso — trocar de celular sem backup significa perder todo o histórico financeiro.
